- 日期：2026-09-24

## 1. 已确认的产品定位

Git Branch Pruner 当前定位为轻量、快捷、可视化的本地分支清理工具，服务于“需要整理本地分支的开发者”。

- 不将受众限定为负责合并的人员，或某一种团队工作流。
- 当前聚焦让用户看懂本地分支状态、选择并安全地批量删除本地分支。
- 分支状态准确、删除安全优先。
- 本地分支管理工具仅保留为未来可能性，创建、切换等能力不因这一可能性成为已承诺的新增功能。
- 完整 Git 管理器不作为当前方向，不自行扩展到删除远端分支或自动清理。
- 不再以 IntelliJ IDEA 的 Git 管理器作为当前方向的设计参照。用户重新查看后认为对当前方向没有借鉴意义。
