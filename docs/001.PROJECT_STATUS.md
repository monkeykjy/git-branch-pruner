# 项目状态与后续方向

更新日期：2026-09-24。包版本仍为 0.1.1，本轮改动尚未发布。

## 已确认的产品方向

当前定位为轻量、快捷、可视化的本地分支清理工具，服务于需要整理本地分支的开发者。优先准确状态与安全删除，管理工具仅为未来可能性。最新方向见 [007.产品方向](007.PRODUCT_DIRECTION.md)。创建本地分支已从第二轮当前范围移出并暂停。

- 打开界面立即读取本地分支和缓存的远程引用，不自动联网。
- Ahead / Behind 是每个本地分支与其实际远端上游各自独有的 commit 数量，不与统一的 main 比较。
- 切换、提交、创建/删除和外部 fetch 引起的本地 Git 变化自动反映到界面。
- 用户点击“更新远端状态”才由插件主动 fetch/prune；失败后保留本地状态。
- 用户负责本轮真实界面与工作流实测，步骤见 [005.手动验收](005.MANUAL_TESTS.md)。

## 本轮已实现

- 结构化 refs、upstream 与 worktree 读取，当前分支置顶。
- Ahead / Behind、已同步、无上游、上游引用缺失、明确比较对象。
- Git 元数据变化监听与事件合并，支持普通仓库和 linked worktree；更新保留有效勾选、搜索和滚动位置。
- 本地搜索、分支切换、单独的本地刷新和远端更新按钮。
- 远端更新保留列表，支持取消和 30 秒超时；本地命令 10 秒超时；继承现有 Git 代理/认证配置。
- 参数数组执行 Git、HTML 转义、nonce CSP、消息校验。
- 普通删除使用 -d；强制删除独立确认；执行层保护当前分支、main/master、已识别默认分支和 worktree 占用分支。
- 批量逐项结果、实际业务测试、可生成的本地实测 fixture。
- 按用户要求，手动测试环境统一生成到项目的 `../tmp/demo/run-XXXXXX/`，每次生成独立环境。

2026-09-24 按用户要求撤回新版展示样式，恢复以旧版为基准的紧凑列表、间距和状态徽标；窄侧栏允许换行。搜索、切换、实际上游与 Ahead/Behind、自动刷新、删除保护和安全渲染继续保留。本次没有恢复旧版的远程有/无二分判断或强制删除默认行为，也没有新增管理功能。

上述为代码状态，不代表已完成所有平台和用户体验验收。回退后的实际视觉效果仍由用户验收。
